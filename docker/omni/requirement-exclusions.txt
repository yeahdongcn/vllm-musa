# Distributions dropped from vLLM-Omni's requirements before it is installed on
# the pinned vLLM-MUSA base, one per line as `name  # why`.

# The MUSA foundation is a contract: torch, torch_musa, vllm, numpy and the rest
# were built and validated together, and the build fails rather than move one.
# A requirement that cannot coexist with that contract therefore has only three
# honest outcomes -- bump the foundation, drop the requirement, or do not build
# the image. This file records the second, with the reason it is safe.
#
# An entry is only defensible when the feature degrades cleanly without the
# package. Check that the importing code actually tolerates its absence before
# adding one, and say so here.
